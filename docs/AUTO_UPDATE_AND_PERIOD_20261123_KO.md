# 월요일 자동 업데이트 및 기간/최신화 안내 — 2026-11-23

기준 저장소: https://github.com/Nagyeong3/openwebui-dashboard-v2

## 자동 업데이트

- 한국 시간 매주 월요일08:30에 일반 업데이트(quick)를 실행합니다. 데이터→토큰→질문 분류 순서, 최초 수집 시 full 승격, 각 원천의 마지막 성공 기준 수집 방식은 수동 업데이트와 같습니다.
- 실행기는 FastAPI 서버 안에서 동작하며 브라우저나 외부 인터넷 연결이 필요하지 않습니다. 운영 서버/대시보드 프로세스와 원천 서버들이 실행 중이어야 합니다. 기존처럼 Uvicorn --workers 1을 사용합니다.
- 실제 .env의 `DASHBOARD_AUTO_UPDATE_ENABLED=true`로 활성화합니다. 환경변수가 없을 때도 서버의 from_env 기본값은 true입니다. false로 끄면 수동 업데이트는 계속 사용할 수 있습니다. 설정을 바꾸면 서버를 재시작합니다.
- 예약 시각을 놓쳤거나 수동/다른 원천 작업이 진행 중이면 예약 시각으로부터24시간 이내15초 간격으로 재확인하여 한 번 보충합니다. 그 이상 지난 주차를 한꺼번에 재실행하지 않습니다. 보충 시간 안에 처음 배포/재시작하면 바로 실행될 수 있습니다.
- 실행 이력에 예약 시각을 고유하게 기록하여 같은 주차를 재시작/동시 확인해도 중복 실행하지 않습니다. 실패한 예약을 자동 무한 재시도하지 않으며 운영 화면에서 실패 항목 재시도/계속하기로 처리합니다. 실행 도중 강제 종료 시 기존 임대 만료 후 중단 상태를 표시하고 수동 계속하기를 사용합니다.
- 사용자가 일시 중단한 작업은 자동으로 취소하거나 이어 실행하지 않습니다. 예약 작업도 기존 일시 중단/중단/계속하기 기능을 사용합니다.

운영 화면에 예약 켜짐/꺼짐, 다음 예약 시각 또는 실행 대기를 표시합니다. 자동 작업도 같은 /operations/status 응답에 activeRunId와 단계별 통계를 기록하므로 '자동 업데이트 진행 중', 데이터·토큰·분류 진행 및 최근 실행 내역에 나타납니다. 대기 중15초, 실행 중3초 간격으로 조회하며 상태 조회 오류 후에도 재시도합니다.

## 데이터 기준 시각과 미반영 안내

개요 상단에는 선택 기간, 사용량 데이터 기준, 토큰 데이터 기준만 표시하며 시각은 한국 시간 분 단위까지 표시합니다. 가장 최근 메시지 시각은 활동이 없을 때 최신화 여부와 다르므로 사용하지 않습니다. 각 캐시의 마지막 성공 수집 기준 시각을 사용합니다. 기존 수집 기준은 마지막 성공 수집을 시작한 시각으로, 완료 시각으로 오인하지 않도록 '데이터 기준'으로 표시합니다.

선택 종료일(오늘을 포함하면 현재 시각)보다 기준 시각이 오래됐거나 수집 이력이 부족하면 빨간 윤곽 삼각형 경고 아이콘과 '업데이트 필요'만 표시합니다. 상세 구간·로그 안내는 표시하지 않습니다. 15분 이내의 정상 수집/게시 지연은 경고하지 않고 기준 시각만 표시합니다. 과거 조회 기간이 수집 기준보다 이전에 종료되었다면 최신 날짜와 차이가 나도 불필요한 기간 경고를 표시하지 않습니다. 토큰 수집 시작일이 선택 시작일보다 늦거나 아직 수집된 원천 데이터가 없을 때도 동일한 간단한 경고를 사용합니다. 미수집 시각은 —로 표시합니다. 업데이트 실행/이력의 상세 진행은 운영 화면에 유지합니다.

이 표시는 데이터의 모든 누락/과거 수정까지 검증했다는 뜻은 아닙니다. 원천 API에서 제공된 마지막 성공본의 시점을 안내합니다. 기간 변경만으로 원천 수집을 실행하지 않습니다. 개요는 일반30초/원천 수집 중5초 간격으로 캐시를 재조회하고 실패 시 기존 결과를 유지하며 안내 후 재시도합니다. 새 동기화 성공본이 생기면 기준 시각과 통계가 갱신됩니다.

## 기간 선택

- '이번 달'·'최근7일' 등은 마지막 수집일이 아니라 한국 시간 오늘 기준입니다. 오래된 데이터 때문에 조회 기간이 과거로 이동하지 않습니다.
- URL의 명시적 기간이 우선이며, 없으면 localStorage의 `oui-dashboard-period-v1`에 저장된 이전 선택을 사용합니다. 저장값이 없거나 손상/잘못된 날짜면 이번 달이 기본입니다.
- 이번 달 같은 상대 기간은 종류만 저장하여 재방문한 현재 날짜에 맞춰 이동합니다. 기간 지정은 선택한 시작일/종료일을 그대로 복원합니다. 기간 이외 조직·검색 등의 값은 새 저장 항목에 포함하지 않습니다.
- 선택 버튼에는 `2026.11.01 ~ 2026.11.20`처럼 선택 날짜를 표시합니다. 펼친 메뉴의 옵션명은 '기간 지정'을 유지합니다. 조직 필터 초기화도 선택 기간은 유지합니다.

## 운영 반영

1. 진행 중인 업데이트를 안전하게 중단하고 대시보드 서버를 종료합니다.
2. 실제 .env, CSV, 분석/토큰/분류/운영 DB를 백업합니다. SQLite는 서버 종료 후 복사합니다.
3. ZIP의 backend_v2 전체와 frontend_v2/dist 전체를 교체합니다. 기존 .env/CSV/DB는 유지합니다.
4. 실제 .env에 다음 값을 확인합니다. .env.example로 실제 설정을 덮어쓰지 않습니다.

```dotenv
DASHBOARD_AUTO_UPDATE_ENABLED=true
```

5. 기존 환경에서 재시작합니다.

```bat
conda activate oui-dashboard-v2
python -m uvicorn backend_v2.app:create_app --factory --host 0.0.0.0 --port 8011 --workers 1
```

6. Ctrl+F5 후 운영 화면의 예약·다음 실행과 개요의 데이터 기준 시각을 확인합니다. 브라우저를 닫아도 서버는 종료하지 않아야 자동 실행됩니다.

외부 스케줄러/신규 Python 패키지/전체 재수집은 필요하지 않습니다. 운영 DB에 origin/scheduled_for 열과 고유 인덱스를 자동 추가하며 기존 이력을 보존합니다. DB 원본을 유지하고 백업한 코드/운영 DB를 함께 복원하면 롤백할 수 있습니다.
