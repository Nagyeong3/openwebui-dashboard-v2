# 보고 지표 후속 수정 — 2026-11-17

기준 저장소: https://github.com/Nagyeong3/openwebui-dashboard-v2

## 반영 기능

주간 메시지 추이는 저장된 assistant 응답 수 기준 선그래프로 변경했습니다. 월~일 한국 시간, 일부 주 표시, 기간 총계와 최고 주간 수를 유지합니다.

팀장 순위는 질문 수 공동순위(1,1,3)를 양 기간에 동일 적용합니다. 증감은 이전 순위 - 현재 순위이며 ▲2, ▼1, 0처럼 표시합니다. 이전 사용량 0인 사용자도 이전 공동순위로 비교합니다. 이전 이력이 부족하거나 전체 기간이면 — 표시합니다. 신규 사용 문구는 표시하지 않습니다. 별도 순위 비교 기간 설정은 유지합니다.

## 개요 증감률

계산식은 (현재 값 - 이전 값) / 이전 값 × 100이며 소수점 한 자리까지 표시합니다. 양쪽 0은 0.0%, 이전만 0이면 비교 불가입니다. 카드의 증감 표시 위에 마우스를 올리거나 키보드로 포커스하면 비교 기간과 이전 값 또는 계산 불가 사유를 볼 수 있습니다. CSV에도 10개 지표의 현재/이전 값, 증감률, 비교 기간 및 상태를 기록합니다.

| 지표 | 비교 기준 |
| --- | --- |
| 활성 사용자, 총 질문 수, 총 채팅방 수, 파일 첨부 질문, 평균 질문/채팅방, 활성 팀장 | 선택 기간 직전의 동일 길이 기간 |
| 총 토큰 | 동일 기간의 LiteLLM 토큰 로그. 수집 시작이 비교 기간보다 늦으면 비교 불가 |
| 전체 사용자 수 | 현재 OpenWebUI 명부 수만 있음. 과거 명부 이력이 없어 비교 불가 |
| 최근 30일간 접속자, 일일 사용자 평균 | 선택 종료일까지 30일과 그 이전 30일 |

일반 지표의 전체 기간은 이전 동일기간이 없어 비교 불가입니다. 30일 지표는 전체 기간에서도 마지막 수집일을 기준으로 이전 30일과 비교합니다. 일일 평균은 사용이 없는 날짜도 포함하여 30으로 나누며, 증감률 계산은 반올림 전 평균을 사용합니다. 평균 질문/채팅방도 반올림 전 비율로 증감률을 계산합니다.

최근 30일간 접속자는 사용자 요청에 따른 제목이며 실제 로그인 수가 아닙니다. 질문 1건 이상인 고유 사용자 수이고 카드 설명에 기준을 표시합니다. 과거 조직과 명부는 현재 기준이며 인사 변동을 복원하지 않습니다. 메시지 기반 비교는 저장된 이력이 이전 기간까지 존재하는 경우에 제공합니다. 수집되지 않은 과거 데이터는 복원하지 않습니다.

## 운영 서버 반영

1. 실행 중인 분류/업데이트를 중단한 뒤 대시보드 서버를 종료합니다.
2. 기존 코드와 실제 .env, CSV, DB를 백업합니다. SQLite DB는 서버 종료 후 복사합니다.
3. 새 ZIP의 backend_v2 전체와 frontend_v2/dist 전체를 교체합니다. 소스 관리 시 frontend_v2/src 및 설정 파일도 같이 반영합니다.
4. 실제 .env, CSV, DB와 기존 Conda 환경은 유지합니다. .env.example을 실제 .env 위에 덮어쓰지 않습니다.
5. 기존 환경을 활성화하고 프로젝트 루트에서 실행합니다.

```bat
conda activate oui-dashboard-v2
python -m uvicorn backend_v2.app:create_app --factory --host 0.0.0.0 --port 8011 --workers 1
```

6. 브라우저 Ctrl+F5 후 개요 증감률, 주간 선그래프, 팀장 순위 숫자를 확인합니다. API와 프런트를 함께 교체해야 합니다.

새 의존성 설치나 DB 마이그레이션, 전체 재수집/재분류는 필요하지 않습니다. 비교 데이터가 부족한 경우에만 기존 운영 업데이트 기능으로 수집 상태를 확인합니다.

## 검증 결과

백엔드112개·프런트34개 테스트와 TypeScript/API 빌드 통과. 이전 사용량0의 공동순위, 10개 지표 HTTP 응답, 사용자 명부 비교 불가, 토큰 증감률과 수집 시작 범위 부족, 0 기준/감소/변동 없음, 비교 배지 렌더링을 자동 검증했습니다. ZIP 내부 파일 체크섬과 CRC도 점검합니다. 실제 폐쇄망 원천 연결은 미검수이며 브라우저 시각 검수는 Chromium 실행 실패로 완료하지 못했습니다.
